Code cheat sheet

game.clicker = "🐶";
What you click. An emoji, or a picture name like "dog".
game.background = "lightblue";
Screen color. Also try game.buttonColor and game.textColor.
addUpgrade("Name", "🦴", 25, { perClick: 1 });
Something to buy. Cost 25. Use perClick or perSecond.
addPrize("Name", "🏆", 100);
Unlocks after earning 100 points total.
whenClicked(function() { ... });
Code that runs every time you click.
everySecond(function() { ... });
Code that runs once every second.
say("Hi!");
Shows a message under the button.
addPoints(10);
Gives points. Use a minus number to take them away.
randomChance(20)
True about 20 out of 100 times. Great for surprises.
randomNumber(1, 6)
A random whole number from 1 to 6.
getPoints()
How many points you have right now.
owns("Name")
How many of an upgrade you've bought.
game.clickEffect = "confetti";
What bursts out when you click: "sparkles", "confetti", "stars", "hearts", "bubbles", "ring", "clicker", "none" — or any emoji or picture name!
game.effectAmount = 12;
How many pieces burst out.
game.shake = true;
The game shakes when you click.
game.clickSound = "coin";
Sound for each click: "pop", "coin", "laser", "boing", "kick", "snare", "clap", "hat" or "none".
game.miniClickers = 3;
How many little copies of your clicker pop out each click. 0 turns them off.
addBonus("Lightning", "rare", { multiplier: 3, seconds: 10 });
A glowing special that sometimes pops out. Tap it before it fades! Rarity can be "common", "rare", "epic" or "legendary". It can give { points: 50 }, a power-up with multiplier + seconds, or a secret prize with { prize: "Name" }. Add icon: "⚡" to use a different picture.
addBonus("Robot Hand", "epic", { autoClick: 60 });
A special that clicks for you for 60 seconds. Add clicksPerSecond: 8 to make it faster (starts at 5).
autoClick(60, 5);
Turn on the auto-clicker from your own code: 60 seconds, 5 clicks a second.
game.autoIcon = "🤖";
The picture that does the auto-clicking. Starts as 👆.
addPrize("Crown", "👑", "secret");
A secret prize you can only get from a special.
game.chances.legendary = 1;
Chance out of 100 for each click. Starts at common 5, rare 2, epic 0.7, legendary 0.2.
game.bonusTime = 6;
How many seconds a special stays before it disappears.
unlockPrize("Crown");
Give a prize right now from your own code.
game.rebirthCost = 5000;
Points needed to rebirth: start over, but everything earns more. Doubles each time. Use 0 to turn rebirths off.
game.rebirthBonus = 1;
Each rebirth adds this much: 1 means x2, then x3, then x4...
whenRebirth(function() { ... });
Code that runs after a rebirth. getRebirths() tells you how many.
effect("ring");
Make an effect happen right now (great inside whenClicked).
playSound("laser");
Play a sound right now.

Make a soundtrack

Tap squares to turn sounds on. The grid plays left to right, then loops forever — and keeps playing while you play your game.
